# NIZ Camera — версия 1.0 (первый прототип)

Android-приложение для совместимой видеосъёмки на устройствах с CameraX. Интерфейс тёмный, в стиле профессиональных кинокамер.

## Что уже реализовано
- Предпросмотр камеры.
- Переключение передней/задней камеры.
- Запись MP4 со звуком (если разрешён микрофон).
- Выбор качества UHD / FHD / HD / SD с автоматическим переходом на доступное качество.
- Сохранение в `Movies/NIZ Camera`.
- Разрешения Android запрашиваются у пользователя.

## Важные ограничения прототипа
Это первая рабочая основа, а не полный аналог Blackmagic Camera. Ручные ISO, выдержка, фокус, баланс белого, LUT, Zebra, Focus Peaking и гистограмма пока не реализованы. Их можно добавлять только после проверки, какие Camera2-параметры реально предоставляет камера Realme C30s. Выбор качества автоматически понижается, если выбранный режим не поддерживается.

## Сборка APK
1. Установить Android Studio на Windows.
2. Открыть в Android Studio папку `NIZCamera` (распаковать архив перед открытием).
3. Дождаться Gradle Sync и установки Android SDK 35, если Android Studio предложит.
4. Выбрать **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
6. Перенести APK на Realme C30s и установить. При необходимости разрешить установку приложений из выбранного источника.

Минимальная версия Android: 6.0 (API 23). Целевой SDK проекта: 32.
