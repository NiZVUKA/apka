# NIZ Camera — облачная сборка

Это проект Android-приложения NIZ Camera. Android Studio и Gradle Wrapper на компьютере не нужны: GitHub Actions сам соберёт APK в облаке.

## Что умеет первая версия
- предпросмотр камеры;
- фото и видео;
- переключение передней/задней камеры;
- цифровое приближение;
- фонарик, если он поддерживается камерой.

Важно: доступные разрешение, частота кадров и ручные настройки зависят от возможностей телефона. Это первая базовая версия, а не полный функциональный клон Blackmagic Camera.

## Как получить APK
1. Создай пустой репозиторий GitHub или открой свой репозиторий `NiZVUKA/Apk`.
2. Загрузи **содержимое архива целиком** в корень репозитория. В корне должны сразу лежать `app`, `.github`, `build.gradle.kts`, `settings.gradle.kts` и `gradle.properties`. Не загружай всё внутрь дополнительной папки `NIZCamera`.
3. Открой вкладку **Actions**.
4. Выбери **Build NIZ Camera APK**.
5. Нажми **Run workflow** → **Run workflow**.
6. Дождись зелёной галочки у сборки.
7. Открой завершённую сборку внизу страницы и скачай артефакт `NIZCamera-debug-apk`.
8. Распакуй скачанный ZIP — внутри будет `app-debug.apk`. Перенеси его на телефон и установи.

Если репозиторий уже содержит старую папку `NIZCamera`, не смешивай её с этим проектом: файлы нового архива должны находиться непосредственно в корне репозитория.
